## Troubleshooting Common Issues

Install issues? Re-register the browser extension after a browser major update.  
Performance problems? Keep the temporary folder on the same drive as the destination.  
License/activation? Reduce the connection count if a server rejects parallel requests.  
Compatibility? Check the scheduler is enabled before relying on an overnight run.  
Update failures? Exclude the temporary folder from antivirus real-time scanning.
